# Как внести вклад

- **Данные** (`data/`): присылая PR или Issue, вы соглашаетесь, что ваш вклад распространяется под **CC BY-NC-SA 4.0**.
- **Код** (`web/`, `android/`, `scripts/`): вклад распространяется под **GNU AGPL-3.0**.
- Не копируйте тексты, инструкции и картинки с 4PDA, XDA и других сайтов — только ссылки и короткие факты своими словами.
- Не уверены в поле — ставьте `unknown`/`null`, ничего не выдумывайте.
- Фото — только со свободной лицензией (Wikimedia Commons CC BY / CC BY-SA / PD) или ваши собственные с согласием на CC BY-SA.
- Перед PR: `npm install && npm run validate`.

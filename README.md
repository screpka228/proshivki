# Прошивки

Помощник по кастомным прошивкам. Введите модель телефона (или откройте APK — он сам определит устройство) и узнайте: можно ли разблокировать загрузчик, есть ли рекавери, какие кастомные прошивки существуют, насколько это сложно, и где обсуждение на 4PDA и XDA.

Состоит из трёх частей: **база** (`data/`), **веб-версия** (`web/`) и **Android-приложение** (`android/`). Плюс [сборщик базы](tools/collector).

## Как пользоваться

1. Введите модель или кодовое имя (работает по-русски и с опечатками) → откроется карточка.
2. В APK сверху карточка «Этот телефон» + текущее состояние загрузчика (root не нужен).
3. Тема — кнопка ◐ в шапке (10 тем, по умолчанию «Мягкий светлый»).
4. Нет модели — кнопка «Добавить» откроет готовый GitHub Issue.

APK не содержит базу: при открытии качает лёгкий `index.json` (проверка не чаще раза в сутки, по ETag), карточку и фото — только когда вы их открыли. Кеш ≤ 5 МБ, в настройках есть «Очистить кеш», офлайн показывается то, что уже открывали.

## Как добавить модель

- Через [Issue «Добавить / исправить модель»](../../issues/new?template=device.yml), или
- PR с файлом `data/devices/<codename>.json` по схеме `data/schema.json`. Локальная проверка: `npm install && npm run validate`. Индекс (`data/index.json`) собирает `npm run build:index` — руками не правьте.

Правила: только ссылки и короткие факты своими словами; не копировать тексты/инструкции/картинки с 4PDA, XDA и других сайтов; не уверены — `unknown`/`null`. Подробнее — [CONTRIBUTING.md](CONTRIBUTING.md). Файлы, созданные сборщиком, помечены `"manual": false`; уберите флаг (или поставьте `true`) после ручной правки, и сборщик больше не тронет файл.

## Разработка

```bash
npm install
npm run validate          # проверка базы по схеме
npm run build:index       # пересобрать data/index.json
node scripts/serve.mjs    # http://localhost:8080/web/
node scripts/fetch-fonts.mjs   # скачать шрифты (OFL) локально в web/fonts
```

Веб: статический сайт без трекеров и CDN, деплой на GitHub Pages (`.github/workflows/pages.yml`). Android: см. [android/README.md](android/README.md). Релиз APK — тег `v*`; подпись берётся из секретов `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, один ключ для всех версий; keystore не коммитьте.
